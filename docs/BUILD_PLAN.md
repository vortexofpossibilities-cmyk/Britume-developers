# Build plan

## Phase 1 — Foundation
- [ ] Configure environments and database
- [ ] Implement registration, verification, login and recovery
- [ ] Add secure sessions, rate limits and audit events
- [ ] Build developer profile and onboarding persistence
- [ ] Implement Google OAuth connection with least-privilege scopes
- [ ] Connect dashboard to real persisted data

## Phase 2 — Developer tools
- [ ] Application records and supported Google Play import
- [ ] Application detail pages
- [ ] Release workflow and upload validation
- [ ] Reporting ingestion and freshness indicators
- [ ] Review retrieval and supported reply operations

## Phase 3 — Complete platform
- [ ] Notification delivery and preferences
- [ ] Workspace membership and role enforcement
- [ ] Security centre and session management
- [ ] Settings, export and deletion workflows
- [ ] Support ticket workflow
- [ ] Billing and subscription lifecycle

A checklist item is complete only after implementation and tests, not merely planning approval.
